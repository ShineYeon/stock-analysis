## 1단계 — 데이터 파이프라인 완성

- [ ] 기존 ECOS 4종(환율·외환보유액·기준금리·국고채 수익률)을 정식 수집 작업으로 완성한다.
- [ ] 노트북에만 있는 경기선행지수, CPI, M2, 뉴스심리지수를 스키마·모델·수집기로 승격한다.
- [ ] 종목 마스터와 전 종목 일별 OHLCV/거래대금/시가총액을 적재한다.
- [ ] 종목별 외국인 순매수와 보유비중을 우선 적재한다. 데이터 제공처, 갱신 시각, 결측 기준을 문서화한다.
- [ ] DART 재무계정 수집을 별도 파이프라인으로 만들고, 기업코드-종목코드 매핑을 관리한다.
- [ ] 재실행해도 중복 없이 갱신되는 UPSERT, 재시도, 로깅, 수집량 검증을 구현한다.

완료 기준: 매 거래일 후 모든 P0 데이터가 동일한 스케줄로 수집되고, 각 테이블의 최신일·행 수·결측률을 확인할 수 있다.

## 2단계 — 가설 검증과 피처 생성

- [ ] 시장 전체와 종목 단위의 외국인 수급 피처를 만든다: 1/5/20/60일 순매수, 거래대금 대비 비율, 연속 매수일, 보유비중 변화, 수급 급변 z-score.
- [ ] 거시 피처를 만든다: 환율 변화·변동성, 금리 수준/변화, 장단기 금리차, CPI/M2/경기선행지수 변화, 뉴스심리지수.
- [ ] 종목 피처를 만든다: 모멘텀, 변동성, 거래량 이상치, 최대낙폭, 밸류에이션, 실적 변화, 업종 상대강도.
- [ ] 외국인 수급이 향후 1·5·20·60 거래일 초과수익률과 변동성에 미치는 관계를 업종·시총별로 분석한다.
- [ ] 환율·시장수익률·업종수익률·실적 이벤트를 통제한 회귀/패널 분석을 수행한다.
- [ ] 시계열 분할(walk-forward)과 표본 외 구간으로 가설을 검증한다.

완료 기준: “어떤 조건에서, 어떤 종목군에, 어느 예측 기간 동안 외국인 수급이 유효한가”를 수치와 재현 가능한 분석 코드로 답할 수 있다.

## 3단계 — 신호·알림·백테스트

- [ ] 설명 가능한 규칙 기반 베이스라인을 먼저 만든다. 예: 외국인 순매수 급증 + 환율 안정 + 업종 모멘텀 양호.
- [ ] 기회 점수와 위험 점수를 분리한다. 높은 기대수익과 높은 위험을 하나의 점수로 섞지 않는다.
- [ ] 알림 조건을 정의한다: 외국인 매수 추세 이탈, 보유비중 급감, 환율 급등, 변동성 급등, 유동성 악화, 손실 한도 초과.
- [ ] 신호 발생일 이후의 수익률·최대낙폭·승률·회전율·거래비용 후 성과를 기록한다.
- [ ] 단순 수급 추종, KOSPI 보유, 업종 모멘텀 등 베이스라인과 비교한다.
- [ ] 데이터 누수, 생존자 편향, 과최적화를 점검한다.

완료 기준: 각 신호에 대해 산출 근거, 예상 보유기간, 과거 성과, 실패 조건, 위험 등급을 제시할 수 있다.

## 4단계 — 사용자 제공 기능

- [ ] 종목 상세 화면: 외국인 심리·수급 추이, 거시 환경, 펀더멘털, 최근 신호 근거.
- [ ] 시장 화면: 외국인 위험선호 지수, 업종별 자금 흐름, 경보 현황.
- [ ] 알림 채널과 빈도, 관심종목, 위험 민감도를 사용자별로 설정한다.
- [ ] 모델/규칙 버전, 데이터 기준일, 면책 및 한계를 UI에 표시한다.

## 가장 먼저 할 5개 작업

1. 노출된 ECOS 키를 폐기·재발급한다.
2. `requirements.txt`, 설정 모듈, 스키마 마이그레이션을 정리해 재현 가능한 실행 기반을 만든다.
3. 종목 마스터·일별 가격·종목별 외국인 순매수/보유비중을 정식 적재한다.
4. 기존 거시지표 수집을 노트북에서 파이프라인과 스키마로 옮긴다.
5. 외국인 수급 피처와 향후 수익률을 이용한 첫 walk-forward 검증을 만든다.
